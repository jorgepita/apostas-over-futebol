## Notes for the Next Session

- **Any new UI text must be written in PT-PT from the start.** Do not add an English string anywhere in `index.html` intending to translate it later — that is exactly the drift this session's entire scope existed to fix.
- **The recurring "duplicate inner label" trap:** several older sections use a pattern of `<div class="section-header"><span class="section-header-title">X — Título em PT</span></div>` immediately followed by a `<div class="card">` whose *own* inner `<div>` repeats the section's English name (e.g. "Action Engine", "Model Calibration", "Strategy Validation", "Edge Validation", "Learning Center" were all found and fixed this session). If you ever add a new lettered analytics section, check both the outer section header *and* the first inner label inside its card.
- **`ptLabel()` / `PT_LABEL_MAP`** (defined near `escapeHtml()` in `index.html`) is the established pattern for translating a label that is also used as an internal comparison key (e.g. `'Broken'`, `'HIGH'`, `'PROMOTE'`). If you add a new rule engine with English internal status codes that also get displayed, reuse this helper — add the new key to `PT_LABEL_MAP` rather than inventing a second lookup or renaming the internal constant.
- Whitelisted terms that are **intentionally** left in English (do not "fix" these): `ROI`, `Edge`, `Scout`, `Bot`, `Strategy Lab`, `JSON`, `CSV`, `API`, `GitHub`, `Railway`, `Cloudflare`, `R2`, `BTTS`, `Over 2.5`, `STRONG BUY`/`BUY`/`NEUTRAL`/`AVOID`, and abbreviations `W-L-P`, `WR`, `P/L €`, `Kickoff`, `Man n`/`Bot n`.
- The Playwright browser binaries, `node_modules`, and all test scripts used this session live entirely in a scratchpad temp directory, not the repository — nothing was added to any committed file for tooling purposes.
